# noi 的叙事判断法

**以作者《Storytelling.Skill 使用手册》为准。** “好叙事 = 好 Vision × 好剧本 × 持续履约”。Vision 取商业成功、社会正义、创始人底色的交集；剧本是通往它的一连串真实选择；里程碑经观众见证，才可能形成下一段的期待。下面的早期语料判断用来帮助作这三项决定。关键材料暂缺时，承认这个交集仍待验证。

以下是对文章和口述的归纳。文中的操作规则由整理者推演。作品编号 T、补篇 E01–E04、录音 R、新增 N 供作者在私人核对册回查（与公开历史案例 E001 等分开编号）；使用本 skill 无须持有原稿。取舍由当前主体作出。

| 判断 | 用于策略时做什么 | 典型依据 |
|---|---|---|
| 愿景决定叙事跨度 | 找到主体亲历的变化、它愿意推动的结局和受益者。先问这个主体以什么为成功，规模、利润、自治和作品可能给出不同答案。让具体产品在更长的进程中有位置。 | T02、T07、T19、E01 |
| 经验里长出独立判断 | 找一个常规做法解释不了的事实，写出主体为什么在意、相信什么，以及什么结果会让它修正。资本、同行、真正使用者的选择分别描述。 | T09、T22、R11、R12 |
| 履约给人参与的理由 | 正确、独特、信任、共识与行动是四级诊断。最后一级看他人是否投入时间、金钱、技能或改变选择。以往履约与访谈能支持的范围分别判断。新主体可先承担小承诺。 | T07、T09、R11、R12 |
| 立场在利益冲突时显形 | 找当前最难调和的一笔账。明确主张改变哪一笔收入、哪项功能、哪种用人或合作。选择代价要与未来有因果关系。 | T04、T25、T38、R11 |
| 内部共识有具体的权力结构 | 找持续生产新事件的人，以及谁有权保护长期标准、裁决与短期 KPI 的冲突。把组织分歧写成可决策的选择。能倡议超出岗位的问题，但承诺要由承担者认领。 | T01、T03、T06、T25、R10、R18 |
| Taste 表现在生产中 | 把审美与文化判断落实为资源有限时保住哪条标准、在哪个环节干预、由谁对最终作品负责。经营有效性与创作者的审美偏好可分别评价。 | T12、E02、E04、R13、N05 |
| 参与者会反过来塑造主体 | 面向人才、用户、资本和伙伴共用同一事实。写明各自能改什么、谁会退出、谁承担代价。留意自发参与和商业激励的差别，以及受到外溢影响的人。 | T02、T26、T32、N03、N04、N07 |
| 文化位置影响商业选择 | 识别谁制定评价标准、生产文化作品、决定人才流动。宏观愿景须连到一个真实主体有能力改变的局部。品牌负责人能否参与产品、经营与建设，关系到其判断能否落地。 | T05、T10、T13、T33、T36；T10 同族演讲脑图 |
| 外界能用自己的经验识别进展 | 让人亲手使用、提反例、改决定。不同角色看到同一件事里与自己有关的变化。用主体能自然维持的表达尺度；当主要问题在经营时优先处理经营。 | T08、T17、T24、E03、R19、R22、N02、N06 |
| 下一段剧情要留下生产能力 | 对照一笔短期回报结束之后，是否还留下产品、研究、能力、关系、制度或可承接的作品。说明这些积累如何支持下一次履约。融资、成交和传播可以支撑生产，也可能把主体锁进反复制造同一种信号的激励中。 | T04、T07、T22、E04、N01；本次对话的“蓄势” |
| 反馈可以推翻路径 | 看哪个现实状态改变了；问是否还有别的解释。承诺过大就收窄，用户真正获得价值才考虑放大。保留主体正在解决的难题，让读者看见下一段为什么值得期待。 | T07、T09、T32、R14；反馈处理为工程化设计 |

按具体问题查[78 项咨询判断](author-decisions.md)，可定位每项的作品或录音编号。优先选择会改变本案的一项。

## 当两条道理都对，哪条先用？

- **外界愿意听，内部接不住。** 先去找正在承担承诺的人。和他一起改一次真实选择，就可能开始创造下一幕；若他没有决定权或不同意，让这一幕留在提案里。T01 的内部共识对宣传设限，T06、R10 给 storyteller 参与经营的空间。
- **大家喜欢一则新鲜事，产品究竟服务谁还不清楚。** 用喜欢证明辨识度，把资格留给下一次真实使用。如果产品和商业路径都没定，可以直接交一页诊断，建议观察一个人不受提示时怎么用。前者来自 T09 和咨询工作稿，后者可对照咨询 C03，不能把一次观察换算为市场规模。
- **一边说用户重要，一边得靠资本活下去。** 先帮公司说清眼下真正的出资者；等到要承诺产品方向时，再查谁有独立的使用证据。若一笔钱换来能转到下一单的技术或关系，条件可能值得接；如果只换来下一回要演同样的戏，别替它写成长期信用。T22 与 N01 是不同处境中的判断，不能取一个平均值。
- **行为变了，但故事属于谁？** 用户给一种新行为起的名字比官方先占了一个词有分量；做产品的人先看到的成果可能还没成为其他人的事。分别追到决策者、使用者和观众，找哪一个人有权改变后续，而不是虚构一个“公众”。这项应用来自 T01、T09 和顾问工作稿。
- **一个人靠本事挣到了钱，可你不喜欢他的品位。** 分开判断商业回报、公共价值和创始人的选择。能盈利不自动构成你愿意追的结局；审美不合，也不能宣布这门生意失败。保留事实，再比较主体愿意长期认领哪种结局。见 E01、E04、T07、T12。

## 遇到相反表达怎么用

- **权力和责任。** T02 强调受托表达的边界，T01/T03 主张推动产品与组织变化。策略写出建议和决策人两个层次。
- **融资与真实需求。** T22 警惕投资人偏好代替用户判断，N01 承认特定周期里资金来源会实质牵引研发，并比较传播与榜单驱动的商业效率。分析该主体实际依赖谁，再检查回报之后的生产溢出。不要替作者选掉其中一边。
- **品位与规模。** E01、N03 的规模克制属于有条件的价值立场，E04 也认可自己不欣赏的模式具有经营质量。由承担者选择希望维护的成果。
- **叙事感与真实性。** T08 有强修辞，T09 明确讨论事实边界。把已经发生、希望发生与情境假设分别标出。T35 的反讽、外部节目引入、匿名转写、跨主体的历史评价不作为行动授权。
- **效率与作者性。** E02、R13、N06 对高效生产、结果责任与投入真实注意力分别提出要求。根据任务是谁承担判断、谁承受后果来使用。
- **大愿景与小行动。** T05/T13 探讨文化体系，T08 从小事启动。以能留下什么、能推动谁的决定，连接两种尺度。

## 随材料调用的补充判断

当资料堆里主要是同行评价、融资意向或免费用户，先拆开资金来源、实际使用者、反馈者的利益。哪一类人承受失败后果，决定这些材料能支持哪种结论。对应 N01、N09、N15、N16。

当策略依赖“影响力”或创始人表达，追问接收者为什么愿意付出注意力，以及团队能否持续用自己的工作与人交流。以小范围亲自服务启动，是某些早期主体可用的一种选择。对应 N02、N06、N10、N12a/N12b。

当项目以时代浪潮解释自己，用生产方式、资源分配和受益人的真实变化校验宏观类比。把反讽、外部节目的观点、商业顾问在特定情境下提出的理论标清来源。对应 N08、N11、N13、N14。

## 创业团队来咨询时

以下判断来自咨询过程的二次归纳。按当前问题选用，仍然直接交一页策略。

- **先认清来咨询的人。** 把委托人与实际作决定的人分开。一个人来问怎么做创始人 IP，可能真正要决定的是他愿意承担客户哪部分经营责任。用已有材料给出判断，关键身份缺失时注明条件。
- **挑会改变含义的一笔生意。** 同样的销量，如果未来靠销售硬件和靠数据能力，会要求截然不同的第一批买家。写清谁付钱、谁使用、谁验收，以及这单为下一步证明什么。团队在研究与交付之间摇摆时，看它愿不愿意按一个真实研究问题挑订单，交付结束双方分别留下什么；只为收入做的项目可以单列。
- **分开形成判断与检验判断。** 早期先说一个值得下注的猜想，再设计一次允许参与者自由选择、能推翻它的观察。小样本能支撑下一次决定，其可外推范围另计。产品服务对象还没选清时，一页策略可以只推荐一次产品试验和暂缓的投入。
- **给不同的人保留自己的话。** 现场问句、顾问拟答、创始人自述、他人的亲历与 AI 摘要分别标明。创始人长文中已有贴切主张，优先保留出处，检验这句话改变哪项体验。第一批客户今天的购买理由、公司长期追求、外界关注的行业变化可分层呈现。
- **找能改变产品的第一位伙伴。** 一个专业合作者可能同时参与本地化、试用和信誉背书。说明他能改哪件事、承担什么、为什么愿意。项目若主张创造了一种新行为，先看第二个人能否独立复现，再看参与者如何命名；团队拟定的词和媒体事件只算候选方案。
