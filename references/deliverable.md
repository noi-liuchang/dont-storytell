# 叙事策略一页纸

让读者在第一页看到一件尚未走完的事。标题可以是一个有内容的问题，也可以是一个看来反常、读完就能理解的场面。开头写一段完整的话，带出已经发生的动作、关心它的人、顾问建议押注的方向。接下来用两三段写事情怎样往前发展。真人的动作、当时能看见的东西、将来仍悬着的问题，胜过五个抽象栏目。

商业成功、社会正义、创始人底色仍要在同一个未来里相遇。读者应能从人物、选择与后果里看到三者；证据缺哪一角就写出缺口。正文里分清已发生、顾问判断和设想，必要时用“已经发生 / 建议的下一幕”等自然提示。每个题材用自己的小标题；读者一口气能读懂时，也可以不用小标题。

收在一个明确行动：谁要作哪个决定、对谁兑现什么、什么结果会让建议改变。来源、正反类比、止损条件，放到页脚或文件备注；只有能让剧情转向的类比才进入正文。首屏和主体留给眼前的公司。材料过薄时给一段诚实的短诊断，允许只有一个待核问题，不补写未来三幕。用法见[咨询短稿写法](consultation-craft.md)。

新一页使用 `schema: 3`。下面是虚构的社区电影院，示意格式、事实与设想的界线。

```json
{
  "schema": 3,
  "title": "星期二那场电影，由谁选？",
  "status": "虚构示意 · 候选",
  "opening": "在这个设定里，周二总有空座，却有几位常客每次散场还留下聊半小时。我愿意押这半小时：也许他们有一部想请街坊一起看的片子。",
  "passages": [
    {"text": "影院可以再降一次票价。也可以把一个平日夜场交给一位常客：由他选一部有放映权的片，写下为什么值得看，再自己请人来。片能不能放、场租能不能覆盖，还是影院要扛的账。"},
    {"heading": "第一次让出排片表", "text": "建议先排一晚。如果散场后有人接过下一场的选片权，这家店才有理由把周二留给街坊。不够付一晚成本，就先缩场次。"}
  ],
  "next": "约一位常客一起算一场电影的保本座位数，问他愿不愿意选第一部。"
}
```

必填 `title, status, opening, passages, next`。每段的 `text` 必填，`heading` 可省。 可选 `note` 是不抢正文的顾问校验，`sources` 是含 `label` 和可选 HTTP(S) `url` 的数组。私人原件可只标注可定位的名称。旧版 schema 1、2 及其五栏仍可正常渲染。
