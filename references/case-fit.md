# 让历史材料帮助当前选择

流程第 4 步按需要调用本文件。案例有两个层次，路径帮助理解连续变化，事件帮助比较某个动作。客户剧情仍从客户自己的选择、愿望和约束生长。

| 当前卡在哪里 | 读取什么 | 带回本案什么 |
| --- | --- | --- |
| 只想出一次活动，接不出后续 | [历史路径](story-paths.md)中处境相近的一段 | 上一步留下什么，下一位参与者为何愿意加入 |
| 已有动作，但不清楚条件或代价 | 用下面的脚本查相关事件卡 | 哪项前提不可缺，哪种结果会使建议改变 |
| 不确定该走哪条路 | 查看不同走法的事件或反例 | 可以区分两种解释的一次观察 |

先按真实选择或参与关系检索，不按名气、赛道或产品相似度检索。默认精读最相关的一两条，需要时才扩展。某个动作的风险尚不清楚，再查反例或混合结果，无须每次凑一正一反。检索词须映射为库内机制词，查不到时改用更具体的经营动作或全文词。

**收束条件。** 案例已经改变一项动作、前提或观察，就把改变写入策略，停止检索。一次相关检索和一次收窄仍无贴切材料，可以留空，交一个本地可验证的提议。用户明确要求深入研究时再扩展，不为了完成固定配额一直搜索。

从案例拿来的每一项建议，要检查客户是否拥有相应资源与权限。历史中的结果不保证在本案重现。只读过卡片时按卡片转述，关键历史细节要进入交付、或客户要据此作重大承诺时，再回原始来源核验。不要说自己读了未打开的原文。

案例可以留在顾问依据记录中。对读者理解判断有帮助时，正文简述并附来源；只用于后台校准时不强制在一页纸堆案例号。没有可迁移机制时明确不用，不拿同属一个行业作理由。

### 检索

在 Skill 目录运行。机制词有 交付、验证、取舍、合作、参与、定价、组织、治理、接棒、作品。阶段为 起念、下注、首证、接力、续约、断点。正反指这件事对特定主张提供支持还是挑战，与公司整体评价无关。

```bash
python3 scripts/find_cases.py --tag 接棒 --sign 正例
python3 scripts/find_cases.py --tag 接棒 --sign 反例
python3 scripts/find_cases.py --tag 验证 --tag 治理
python3 scripts/find_cases.py --id E033 E030 E038
```

读卡时分别核对历史事实与顾问对商业取舍、受益人或受损者的解释。112 张卡都标出了生意在哪里、谁会在意；只有 24 张在当前来源里有创始人或当事人来处的具体线索，其余 founder_evidence 留空。证据不足时不得为拼齐 Vision 三角补写动机。无需执行环境时直接按机制或案例号检索 references/casebook.json。库中 102 个事件和 10 项在营机制独立计数；同一主体的不同决定可能成为多张卡，不能当独立企业样本。库偏向留有公开记录的企业和英语来源。现场咨询、无公开记录的小生意及私有项目有自己的证据优先级。没有合适近邻时，继续搜索新的原始记录或显式留空，不能造故事。

### 宽标签翻不出近邻时

先用两个机制交叉，再按第一笔生意的代价缩小范围。以下是进入不同材料的一组路标，不是对这些产业的预设答案。编号只用来定位原卡。

| 当前真正要作的决定 | 三个方向的首选对读 | 什么会让你换路 |
| --- | --- | --- |
| 卖一次硬件，还是挣下一次维护的钱 | E033 跨代升级、E030 零件断供、E038 更新失约 | 旧机更新权、部件和回退条件不在自己手里 |
| 如何把一份工作交给陌生同事 | E035 外人独立修机、E108 有原表可核的简讯、E059 恢复失败 | 必须请作者在场救火，或无人有权叫停 |
| 长期合作能不能在演示前拿订单 | E021 采购方时间压力、E025 独立认证、E018 未确认的资金条件 | 外部承诺方不能签字，或对方没有提前下注的理由 |
| 为什么有人愿意为作品续费 | E048 长期写作后转收费、E047 让出平台分成、E046 会员不足以维持编辑部 | 只有创刊支持，没有第二次付费 |
| 要扩张，团队还能否兑现旧标准 | E065 把经营权交给员工、E056 产能解除排队、E041 扩招后裁员 | 新项目从旧业务抽走了唯一能带教或放行的人 |
| 用户真的变好了吗 | E109 可观察的动作、E110 小范围反复参与、E102 分数被外推 | 新情境无法独立重做，或改善只存在于仪表盘 |
| 经营权与文化权交给谁 | E029 所有权安排、E081 社区认股和排班、E049 文化认同面临租金 | 有舆论支持却没人愿付钱或承担下一班 |

从同一主体借连续事件，是纵向追踪；用不同主体和反方向结果挑战它，是横向检验。两者都不产生统计意义上的成功概率。

若删掉页尾案例号并不改变任何行动，就省去这一条；仅仅同属教育、文化或硬件，不构成可用依据。
